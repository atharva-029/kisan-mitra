# 🌾 Kisan Mitra

### Smart Agricultural Assistance Platform for Indian Farmers

**Kisan Mitra** is a web-based agricultural assistance platform designed to bring useful farming information and tools together in one place. It helps farmers access weather information, mandi prices, crop guidance, government schemes, soil information, and irrigation-related resources through a simple dashboard.

---

## 🚜 Features

### 🌦️ Weather & Regional Information

* Weather information for selected locations
* Regional state, district, and block selection
* Location-based agricultural information
* Interactive weather visualization

### 📈 Mandi Price Optimizer

* Agricultural market information
* Crop-wise mandi price insights
* Helps farmers explore market opportunities and make better selling decisions

### 🌱 Crop Cultivation Guide

* Crop-related cultivation information
* Guidance for different agricultural crops
* Useful information throughout the cultivation process

### 🏛️ Government Schemes

* Agricultural government scheme information
* Helps farmers discover potentially relevant government initiatives and support programs

### 🧪 Soil Information

* Soil-related agricultural information
* Supports better understanding of soil conditions for cultivation

### 💧 Irrigation

* Irrigation-related guidance
* Helps farmers understand water requirements and management

## ⚡ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/atharva-029/kisan-mitra.git
```

### 2. Navigate to the project

```bash
cd kisan-mitra
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on the local development server provided by Vite.

---

## 🖥️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🎯 Vision

Kisan Mitra aims to make agricultural information more accessible by bringing multiple farming resources into a single digital platform.

The long-term vision is to build a smarter agricultural ecosystem where farmers can access reliable information and make more informed decisions about their crops, markets, weather, soil, irrigation, and available government support.
